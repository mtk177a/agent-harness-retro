# 論理系列

再試行や関連する記録と、独立した再発を区別するため、次のルールを使う。

| 証拠 | 扱い |
| --- | --- |
| 同じ `source_ref` の観測。再開後の検証済みの版を含む。 | 1 つの論理情報源として扱う。 |
| 明示された `parent` や `forked_from` の関係。間接的なつながりを含む。 | 1 つの系列として扱う。 |
| サブエージェントの証拠。 | 明示的な関係か正規化された親との関連付けで確認できる場合だけ、親の系列に含める。 |
| 同じ情報源のインスタンス内で、参照が異なる。 | 関係の情報が完全で、提示された文脈にも曖昧さがない場合だけ、独立したものとして数える。 |
| 情報源のインスタンスが異なる。 | 各応答が完全でも、別々のやり取りであることを提示された証拠で確認できる場合だけ、独立したものとして数える。 |
| 同じプロバイダーの情報源が、異なるインスタンスで同じ provider-source fingerprint を持つ。 | コピーされた観測か独立したやり取りかを証拠で区別できなければ、未解決のままにする。 |

証拠が裏付ける必要最小限の関係グラフだけを作る。\
テキストや失敗が似ているだけで、記録をまとめない。\
必要な関係が欠けている場合や曖昧な場合は、不確実性を保ち、該当する情報源を独立した再発の確定的な証拠として数えない。

各系列内の再試行と、独立した系列の数を分けて報告する。
