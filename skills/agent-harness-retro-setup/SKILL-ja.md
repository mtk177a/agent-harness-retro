# Agent Harness Retro の初期設定

振り返りを行うときと同じローカル環境で作業する。

## 1. CLI を確認する

- **実行ファイルを探す** — `agent-sessions --version` を実行するか、利用者が指定した絶対パスの実行ファイルを確認する。[インストールスクリプト](scripts/install-agent-sessions.sh) が指定するコミットからビルドしたものを使う。バージョンの末尾は `-8bc9542a15ed` である。
- **必要に応じてインストールする** — インストール先のディレクトリを利用者と確認する。macOS では Git と Go 1.26 以降が必要である。`sh <skill-directory>/scripts/install-agent-sessions.sh <absolute-bin-directory>` を実行する。インストール先に同名のファイルがある場合は、別のディレクトリを選ぶよう利用者に伝える。`--version` でバージョンを確認し、実行ファイルの絶対パスを控える。

## 2. 記録の保存先を選ぶ

利用者が選んだ Codex や Claude Code の保存先を使う。指定がなければ、どの保存先を使うか尋ねる。一覧を取得する前に、プロバイダーと保存先の絶対パスを確認する。

1. **既存の設定** — 利用者が指定した `--config` のパスを使う。指定がなければ、macOS では `~/Library/Application Support/agent-sessions/config.json` を確認する。選んだ設定ごとに、プロバイダー、ID、保存先を確認する。
2. **環境変数と標準の保存先** — 設定から保存先を選ばなかったプロバイダーについては、環境変数、標準の保存先の順で調べ、使うパスを利用者と確認する。

   | プロバイダー | 環境変数 | 標準の保存先 |
   | --- | --- | --- |
   | Codex | `CODEX_HOME` | `~/.codex` |
   | Claude Code | `CLAUDE_CONFIG_DIR` | `~/.claude` |

3. **利用者が指定する保存先** — `list --limit 1 --provider <provider> --root <absolute-root>` で指定されたパスを確認する。設定ファイルを選んでいる場合は、そのパスも指定する。一覧を取得できた保存先を利用者が登録したい場合は、[利用者が指定した保存先を登録する](#利用者が指定した保存先を登録する) に進む。

## 3. 一覧を取得できるか確認する

選んだ実行ファイルで、確認済みの保存先ごとに `list --limit 1 --provider <provider>` を実行する。設定ファイルを使う場合は、ファイルのパスと確認済みの `--source-instance` を渡す。環境変数や標準の保存先を使う場合は、確認済みのパスを `--root` で渡す。振り返りでも同じ指定を使う。

終了ステータスと JSON の `status`、`data.sources`、`omissions` を確認する。取得できた一覧が空だった場合は、エラーや未対応の場合と区別して伝える。記録の欠落は、次のページが残っている場合と分けて報告する。確認に失敗した場合は、残っている準備を伝える。

使える保存先ごとに、実行ファイルのパス、設定ファイルを使った場合はそのパス、プロバイダー、ID または保存先を伝える。初期設定は一覧の確認で終わる。振り返りは、利用者が証拠と対象範囲を選んでから始める。

### 利用者が指定した保存先を登録する

1. **設定ファイルを確認する** — 既存のファイルを解析できない場合や、[設定の仕様](https://github.com/mtk177a/agent-sessions/blob/8bc9542a15ed85f0b9b341886e920c76b1572d20/docs/ja/cli-json-contract.md#設定の構造) と合わない場合は、ファイルを変更せずに問題を報告する。
2. **登録内容を確認する** — 同じ設定があれば再利用し、追加する場合はそのプロバイダーで未使用の ID を選ぶ。書き込む前に、設定ファイルのパスと `sources` に追加する内容を利用者と確認する。
3. **保存先を登録する** — 既存の設定と ID を保持する。設定ファイルを新規作成する場合は、所有者だけがアクセスできるようにする。手順 3 では登録した ID を使う。
